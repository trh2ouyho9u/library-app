# Random Task Generator

**Автор:** Птичкина Дарья

## Описание
Random Task Generator - это графическое приложение на Python, которое помогает генерировать случайные задачи из предопределенных категорий. Приложение позволяет добавлять новые задачи, фильтровать их по типу и отслеживать историю сгенерированных задач.

## Функциональность
- Генерация случайных задач из предопределенных категорий
- Фильтрация задач по типу (учеба, спорт, работа)
- Добавление новых задач
- Удаление существующих задач
- Просмотр истории сгенерированных задач
- Сохранение данных в JSON файлы
- Валидация ввода (проверка на пустые строки)

## Требования
- Python 3.6 или выше
- Библиотеки: tkinter (входит в стандартную установку Python)

Использование

Генерация задач

1. Выберите тип задачи из выпадающего списка или оставьте "все" для случайного выбора из всех категорий
2. Нажмите кнопку "Сгенерировать задачу"
3. Сгенерированная задача отобразится на экране и добавится в историю

Добавление новой задачи

1. Введите текст задачи в поле "Текст задачи"
2. Выберите тип задачи из выпадающего списка
3. Нажмите кнопку "Добавить"

Удаление задачи

1. Выберите задачу в списке задач
2. Нажмите кнопку "Удалить выбранную задачу"

Просмотр истории

· Все сгенерированные задачи отображаются в разделе "История сгенерированных задач"
· Для очистки истории нажмите кнопку "Очистить историю"

Структура данных

tasks.json

```json
{
    "учеба": ["Прочитать статью", "Решить задачи"],
    "спорт": ["Сделать зарядку", "Пробежка 30 мин"],
    "работа": ["Проверить почту", "Написать отчет"]
}
```

history.json

```json
[
    {
        "task": "Сделать зарядку",
        "type": "спорт",
        "timestamp": "2024-01-15 14:30:00"
    }
]
```

Тестирование

Тест-кейс 1: Базовая генерация

1. Запустите приложение
2. Выберите тип "все"
3. Нажмите "Сгенерировать задачу"
4. Ожидаемый результат: Случайная задача отображается на экране и добавляется в историю

Тест-кейс 2: Фильтрация

1. Выберите тип "спорт"
2. Нажмите "Сгенерировать задачу"
3. Ожидаемый результат: Генерируется задача только из категории "спорт"

Тест-кейс 3: Добавление задачи

1. Введите "Тестовая задача" в поле ввода
2. Выберите тип "учеба"
3. Нажмите "Добавить"
4. Ожидаемый результат: Задача появляется в списке

Тест-кейс 4: Валидация ввода

1. Оставьте поле ввода пустым
2. Нажмите "Добавить"
3. Ожидаемый результат: Сообщение об ошибке "Задача не может быть пустой"

Тест-кейс 5: Сохранение данных

1. Добавьте новую задачу
2. Закройте приложение
3. Откройте приложение снова
4. Ожидаемый результат: Добавленная задача сохранена и отображается в списке
### Команда для запуска
```bash
python main.py
```

Работа с приложением

Добавление книги

1. Заполните поля: "Название", "Автор", "Год"
2. Нажмите кнопку "Добавить книгу"
3. Книга появится в таблице

Удаление книги

1. Кликните по строке с книгой в таблице
2. Нажмите "Удалить выбранную книгу"

Поиск книг автора

1. Введите имя автора в поле фильтра
2. Нажмите "Найти" — останутся только книги этого автора
3. Нажмите "Показать все" — вернутся все книги

Сохранение данных

· Нажмите "Сохранить в файл" — все книги сохранятся в books.json
· При следующем запуске данные загрузятся автоматически

Правила ввода

Поле Требование
Название Не может быть пустым
Автор Не может быть пустым
Год Целое число от 1000 до 2026

    },

        "author": "Фёдор Достоевский",
        "year": 1866
    }
]
```
