# Менеджер личной библиотеки

GUI-приложение для управления личной библиотекой книг с возможностью добавления, удаления, фильтрации и сохранения данных в JSON-формате.

## Возможности

- **Добавление книг** — ввод названия, автора и года издания
- **Удаление книг** — удаление выбранной книги из списка
- **Фильтрация по автору** — поиск книг конкретного автора
- **Сохранение в файл** — экспорт библиотеки в JSON-файл
- **Автозагрузка** — при запуске данные загружаются из `books.json`
- **Валидация** — проверка корректности вводимых данных

## Установка и запуск

### Требования
- Python 3.x
- Стандартные библиотеки: `tkinter`, `json`, `os`

### Команда для запуска
```bash
python main.py
```

Работа с приложением

Добавление книги

1. Заполните поля: "Название", "Автор", "Год"
2. Нажмите кнопку "Добавить книгу"
3. Книга появится в таблице

Удаление книги

1. Кликните по строке с книгой в таблице
2. Нажмите "Удалить выбранную книгу"

Поиск книг автора

1. Введите имя автора в поле фильтра
2. Нажмите "Найти" — останутся только книги этого автора
3. Нажмите "Показать все" — вернутся все книги

Сохранение данных

· Нажмите "Сохранить в файл" — все книги сохранятся в books.json
· При следующем запуске данные загрузятся автоматически

Правила ввода

Поле Требование
Название Не может быть пустым
Автор Не может быть пустым
Год Целое число от 1000 до 2026

Формат файла (books.json)

```json
[
    {
        "title": "Война и мир",
        "author": "Лев Толстой",
        "year": 1869
    },
    {
        "title": "Преступление и наказание",
        "author": "Фёдор Достоевский",
        "year": 1866
    }
]
```
